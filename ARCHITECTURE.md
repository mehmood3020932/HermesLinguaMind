# Hermes Architecture

This root-level page is a quick entry point. The complete architecture is maintained at [`docs/engineering/COMPLETE_ARCHITECTURE.md`](docs/engineering/COMPLETE_ARCHITECTURE.md).

## Key principles

- Local-first AI with provider adapters
- Domain-driven learning services
- Pluggable avatar/companion layer
- Observable, secure, rollback-friendly operations
- Open-source contribution paths for languages, lessons, UX and infrastructure
