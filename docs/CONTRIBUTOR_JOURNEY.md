# Contributor Journey

Hermes is intentionally structured so a first-time contributor can become a long-term maintainer.

```text
Discover → Try → Report → Fix → Review → Merge → Own an area
```

## Beginner

- documentation fixes
- translations
- language examples
- UI copy
- accessibility
- tests

## Intermediate

- Flutter features
- backend endpoints
- STT/TTS adapters
- curriculum logic
- analytics instrumentation

## Advanced

- orchestration
- pronunciation evaluation
- avatar/viseme pipeline
- security
- performance
- deployment/Kubernetes

## Maintainer expectations

Every contribution should be reproducible, licensed, documented, and tested where practical. Do not commit secrets or unlicensed model/voice/avatar assets.
