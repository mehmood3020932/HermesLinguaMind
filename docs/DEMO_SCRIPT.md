# 90-Second Demo Script

## 0–10 seconds — The promise

Show onboarding:

> “I speak Urdu. I want to learn English.”

## 10–25 seconds — The wow moment

Companion says in Urdu:

> “Assalam-o-alaikum! Main aapki English practice mein help karungi. Aaj hum ek short conversation karte hain.”

Then switches to English.

## 25–50 seconds — Real conversation

User speaks naturally. STT transcribes. Hermes responds. TTS speaks. The companion reacts.

## 50–70 seconds — Correction

Show one useful correction rather than a wall of grammar:

> “Almost. Say: ‘I have been learning English for two years.’”

## 70–82 seconds — Memory

Show the next turn adapting to the learner's mistake or level.

## 82–90 seconds — Open source

Show GitHub:

> “The tutor, language packs, integrations and developer tooling are open to the community.”
