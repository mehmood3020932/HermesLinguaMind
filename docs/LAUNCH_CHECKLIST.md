# Public Launch Checklist

## Product
- [ ] One complete native-language → target-language learning loop works.
- [ ] Speech permissions and failure states are tested.
- [ ] TTS fallback is tested.
- [ ] Companion reconnect state is tested.
- [ ] No mock-only behavior is presented as live production inference.

## Engineering
- [ ] Docker stack boots from a clean machine.
- [ ] Database migrations are reproducible.
- [ ] CI is green.
- [ ] Secrets are absent from Git history.
- [ ] Dependency/model/voice licenses are inventoried.
- [ ] Backups and restore have been tested.

## Mobile
- [ ] Android release build works.
- [ ] iOS release build works when applicable.
- [ ] App icon/splash/permissions are production-ready.
- [ ] Crash reporting is configured with privacy controls.

## Community
- [ ] README has demo media.
- [ ] CONTRIBUTING is tested by a new contributor.
- [ ] Good-first-issue backlog exists.
- [ ] Discussions/community channel exists.
- [ ] Code of Conduct and security policy are visible.

## Fundraising
- [ ] Real active-user metrics.
- [ ] Retention cohorts.
- [ ] Speaking minutes and learning outcomes.
- [ ] Cost per active learner.
- [ ] Revenue/conversion if monetized.
- [ ] 10-slide pitch deck with no unsupported claims.
