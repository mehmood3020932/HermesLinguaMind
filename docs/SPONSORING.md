# Sponsoring Hermes LinguaMind

Hermes LinguaMind aims to make high-quality AI-assisted language learning accessible through open source.

## Ways to support

### GitHub Sponsors
If GitHub Sponsors is enabled for the maintainer, use the **Sponsor** button at the top of the repository.

### Cryptocurrency
See [`DONATIONS.md`](DONATIONS.md) for the maintainer's verified public receiving addresses.

### Non-financial support
You can also help by:

- contributing code
- adding a language pack
- improving documentation
- reporting reproducible bugs
- testing releases
- creating tutorials and demos
- translating the interface
- improving accessibility

## Sponsor transparency

Sponsorship does not buy issue priority, security exceptions, or special treatment. Funding should improve the project for the whole community.
