# Hermes Visual Asset Library

The repository intentionally keeps architecture visuals as editable SVG assets so contributors can improve them without proprietary design software.

## Core visuals

- `assets/ultra-system-map.svg` — product/system overview
- `assets/ultra-community-flywheel.svg` — user → contributor → sponsor loop
- `assets/ultra-enterprise-stack.svg` — build → verify → operate
- Existing architecture assets — AI learning loop, delivery architecture, community flywheel

## Design principles

- Dark, high-contrast presentation
- Minimal visual noise
- Accessible labels and alt text in README
- No fake screenshots or fake metrics
- Diagrams describe architecture; they do not claim components are deployed unless the runtime documentation says so
